# Controle de Agentes IA - Cursor / Gemini / Codex

## Objetivo
Registrar auditorias, prompts, execuções e decisões tomadas por agentes de IA no projeto Smart360.

## Regras
- Não executar alterações sem branch.
- Não criar migrations sem autorização.
- Não remover arquivos sem auditoria.
- Não alterar .env, tokens ou credenciais.
- Toda execução importante deve gerar relatório.
- Todo prompt relevante deve ser salvo.
- Toda mudança deve ser validada com manage.py check.
