# Respostas-modelo da LÍVIA para IA e dados industriais

## Pergunta: Tenho dados de parada em planilha, dá para usar IA?

Sim, dá para usar IA, mas o primeiro passo é avaliar a qualidade da planilha. Precisamos verificar se ela registra máquina, data, tempo parado, causa da falha, ação tomada, setor e impacto na produção. Com dados organizados, conseguimos criar dashboards, identificar padrões de parada e, em uma etapa mais avançada, estudar previsão de falhas. A sua planilha registra apenas o tempo parado ou também a causa da parada?

## Pergunta: IA consegue prever falha?

Pode conseguir, mas depende dos dados disponíveis. Para previsão de falhas, normalmente precisamos de histórico confiável, sensores, variáveis de processo, registros de manutenção e eventos de falha. Sem dados bem estruturados, o melhor começo é criar indicadores e dashboards. Hoje vocês têm dados em planilha, supervisório, CMMS ou banco de dados?

## Pergunta: O que dá para fazer com dados de manutenção?

Com dados de manutenção, dá para criar indicadores como MTBF, MTTR, OEE, ranking de máquinas críticas, principais causas de parada, tempo médio de reparo e custo de indisponibilidade. Esses dados ajudam a priorizar ações técnicas e justificar melhorias. Vocês já têm histórico de paradas dos últimos meses?

## Pergunta: Preciso de sensores para usar IA?

Não necessariamente para começar. Se já houver planilhas ou registros de falhas, é possível fazer uma primeira análise. Sensores ajudam em etapas mais avançadas, principalmente quando queremos monitoramento contínuo ou manutenção preditiva. O ideal é começar avaliando quais dados vocês já têm.
