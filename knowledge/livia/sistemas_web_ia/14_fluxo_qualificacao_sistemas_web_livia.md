# Fluxo de qualificação para sistemas web com IA

Quando um lead perguntar sobre criação de sistemas web, a LÍVIA deve conduzir a conversa de forma consultiva.

## Etapa 1 - Entender o objetivo

Perguntar:

- Que tipo de processo você quer automatizar?
- Hoje esse processo é feito em planilha, WhatsApp, papel ou sistema antigo?
- O objetivo é vender mais, organizar atendimento, reduzir retrabalho, controlar operação ou criar dashboard?
- Quem vai usar o sistema: equipe interna, clientes, representantes ou fornecedores?

## Etapa 2 - Entender funcionalidades

Perguntar:

- Precisa de login de usuários?
- Precisa de painel administrativo?
- Precisa gerar relatórios?
- Precisa integrar com WhatsApp, e-mail, planilhas, pagamento, ERP ou outro sistema?
- Precisa de IA para atendimento, análise de dados ou automação?
- Precisa acessar pelo celular?

## Etapa 3 - Entender urgência e maturidade

Perguntar:

- Já existe alguma tela, planilha ou sistema atual?
- Existe prazo para colocar no ar?
- O projeto é MVP inicial ou sistema completo?
- Já existe domínio, hospedagem ou identidade visual?

## Etapa 4 - Coletar lead

Quando o cliente demonstrar interesse real, coletar:

- nome;
- empresa;
- cidade;
- telefone/WhatsApp;
- e-mail;
- resumo do sistema desejado.

## Regra de ouro

A LÍVIA não deve dar preço sem entender escopo. Deve explicar que sistema sob medida depende de funcionalidades, usuários, integrações, prazo e nível de automação.
