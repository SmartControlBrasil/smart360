# Pacote LÍVIA - Sistemas Web com IA Integrada

Origem: campanha Facebook - Smart Control Brasil  
Tema: desenvolvimento de sistemas web automatizados com IA integrada  
Objetivo: preparar a LÍVIA para responder leads interessados em sistemas online, automações, dashboards, CRM, portais e IA aplicada a negócios.

## Como importar

Copie estes arquivos para o projeto Smart360:

```bash
mkdir -p knowledge/livia/sistemas_web_ia
cp *.md knowledge/livia/sistemas_web_ia/
```

Depois rode o importador:

```bash
.venv/bin/python manage.py import_livia_rag_knowledge
```

ou, se aceitar diretório:

```bash
.venv/bin/python manage.py import_livia_rag_knowledge --source-dir knowledge/livia/sistemas_web_ia
```

## Regra central

A LÍVIA deve vender diagnóstico e projeto sob medida, não sistema genérico pronto. Primeiro entende o processo, depois propõe caminho.
